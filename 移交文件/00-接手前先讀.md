## 不可過度宣稱的部分

目前程式具備正式 Let’s Encrypt 簽發、IIS 443 SNI Binding、SYSTEM 自動續期、備份與復原邏輯；但此開發工作區尚未在真實 Windows Server＋公開網域完成端到端驗收。移交後仍須依 `03-Windows-Server實機驗收清單.md` 驗證 UAC、Staging、Production、renewal、reboot、rollback 與舊憑證清理，才可標示為完成生產驗收。

使用者曾詢問介面中的「測試」字樣：

- `Let’s Encrypt Staging／測試憑證` 是正式簽發前必要的安全驗證，必須保留。
- `固定測試版本／下載經測試版本` 指「本工具驗證過 SHA-256 的官方 win-acme 固定版本」，不是 trial 或 beta。這段文案容易誤解，後續可在不改變安全邏輯的前提下改成「已驗證的固定版本」。

## 交付包內容

- `Mstech.IisSslManager/`：主程式乾淨原始碼，排除 `bin/obj/artifacts`。
- `Mstech.IisSslManager.SmokeTests/`：測試原始碼，排除 `bin/obj`。
- `references/`：固定 win-acme 官方套件與當時核對用來源快照。
- `移交文件/`：本套移交說明及重建腳本。
- `SOURCE-FILES.sha256.txt`：移交包內所有檔案的 SHA-256 清單。

不要把 `outputs/MSTECH-IisSslManager-1.1v-win-x64.zip` 當作開發原始碼；那是提供 Windows Server 使用者解壓執行的 self-contained runtime 發行包。
