# 建置、測試與發行操作

以下命令假設目前目錄是解壓後的移交包根目錄。

## 開發需求

- Windows x64。
- .NET 10 SDK。
- WPF／Windows Desktop build support。
- Windows PowerShell 5.1（用於檢查 retention script 與發行腳本）。
- 真實 IIS 測試只可在業主指定的 Windows Server 測試機進行。

## 建立接手基準

```powershell
dotnet --info
dotnet restore .\Mstech.IisSslManager\Mstech.IisSslManager.csproj
dotnet build .\Mstech.IisSslManager\Mstech.IisSslManager.csproj -c Release
dotnet run --project .\Mstech.IisSslManager.SmokeTests\Mstech.IisSslManager.SmokeTests.csproj -c Release
```

預期結果：

- Release：`0 個警告 / 0 個錯誤`。
- Smoke tests：`12/12 smoke tests passed.`。
- FileVersion：`1.1.0.0`。

Retention PowerShell 靜態語法檢查：

```powershell
$tokens = $null
$parseErrors = $null
[System.Management.Automation.Language.Parser]::ParseFile(
    (Resolve-Path '.\Mstech.IisSslManager\Scripts\CertificateRetention.ps1'),
    [ref]$tokens,
    [ref]$parseErrors) | Out-Null
$parseErrors
```

預期 `$parseErrors` 為空。

## Smoke tests 目前涵蓋

1. DNS normalization。
2. DNS rejection／Wildcard rejection。
3. IIS Binding parser。
4. IIS site XML parser。
5. Staging command safety invariant。
6. Production command policy invariant。
7. Secret masking。
8. Elevated result HMAC authentication／tamper rejection。
9. Secure Staging directory。
10. Renewal task single-action allow-list。
11. Retention script HTTP.sys fail-closed check。
12. Application／Assembly version consistency。

任何行為修改都應補測試。涉及 IIS、UAC、ACL、ACME、renewal 或 rollback 時，不可只新增 happy-path test。

## 建立執行版

進入主專案目錄後執行：

```powershell
Set-Location .\Mstech.IisSslManager
powershell -ExecutionPolicy Bypass -File .\build-release.ps1
```

輸出：

- `artifacts\MSTECH-IisSslManager-1.1v-win-x64\`
- `artifacts\MSTECH-IisSslManager-1.1v-win-x64.zip`
- `artifacts\MSTECH-IisSslManager-1.1v-win-x64.zip.sha256.txt`

1.1v 已交付執行版的 SHA-256：

```text
29483E106FBC3940BBE96AFA2B6CA2D822072800E01CC30CFC9F40A947F2E9F1
```

每次重建 ZIP 時 SHA-256 都可能改變；必須以當次輸出的 `.sha256.txt` 為準。

## 發行前人工檢查

- 主畫面版本顯示 `1.1v`。
- About 顯示 Logo、`版本：1.1v`、公司名稱、TEL、FAX、E-mail、地址。
- ZIP 內含 `MSTECH.IisSslManager.exe`、`README.md`、`CHANGELOG.md`、`AGENTS.md`、`THIRD-PARTY-NOTICES.txt`。
- EXE FileVersion 是 `1.1.0.0`。
- 無測試密碼、真實管理員密碼、私鑰、PFX、ACME account secret 或客戶網域資料混入原始碼及發行包。
- 若已導入 Code Signing，必須驗證 Authenticode signature 與 timestamp；目前 1.1v 尚未簽章。

## 版本同步位置

更改版本時必須同步：

- `Infrastructure/AppVersion.cs`
- `Mstech.IisSslManager.csproj`
- `app.manifest`
- `MainWindow.xaml`
- `Views/AboutWindow.xaml.cs`
- `README.md`
- `CHANGELOG.md`
- `build-release.ps1`
- Smoke test 的版本斷言

顯示格式是業主指定的 `1.1v`；Windows/.NET metadata 必須保持數字格式，例如 `1.1.0.0`。
